SquidSpot privacy policy

Updated 29 September 2026 · App package: app.squidspot.eging · Publisher: LabtechApps

Plain-language draft for closed testing. Not legal advice and not a government notice. Have a lawyer review before production release.

Updated 29 September 2026.

SquidSpot does not run a user account server for this build. The app does not ask you to create an account.

On this device only, the app stores a catch log, pins you drop, your chosen region, whether the welcome paywall has been shown, and a demo subscription entitlement. That data stays in local storage. Uninstalling the app removes it. SquidSpot does not upload those records to a SquidSpot server.

The Android app includes a location permission because the Mapbox map library declares it. This build does not request GPS in the app code and does not upload coordinates to SquidSpot.

When a Mapbox token is configured, the native map loads tiles from Mapbox. Those requests include an IP address and are covered by Mapbox’s privacy policy. The web map can load OpenStreetMap tiles through a public tile service.

This build does not use Google Play Billing. The demo Premium button does not take a payment and does not store a card. If a later version sells a subscription, Google Play will process the payment. SquidSpot would not receive a full card number.

This build does not include an advertising SDK and does not sell personal information.

SquidSpot is not directed at children under 13.
